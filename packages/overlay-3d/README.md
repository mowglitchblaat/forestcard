# @forestcard/overlay-3d

Les overlays rendus en WebGL (Pixi 8) : une carte construite à l'affichage avec `@forestcard/layout`, ou son image aplatie en repli ; des effets et des révélations pilotés par une configuration en données ; la scène du booster.

Organisation, contrats d'un effet et d'une révélation, configuration, règles de rendu : `apps/overlay-3d/README.md`. La décision : `docs/adr/0009-overlays-en-webgl.md`.
